About CodeJourney

CodeJourney is a personal educational website created to showcase my learning experience in web development. This website represents my journey in understanding HTML, CSS, and JavaScript while developing creativity, problem-solving skills, and technical knowledge.

Its main purpose is to share what I have learned, present my projects, and demonstrate how technology can turn ideas into reality.

My Learning Hub

Discover the three essential technologies I explored while learning web development.

HTML

HTML stands for HyperText Markup Language. It provides the structure and content of a website.

CSS

CSS stands for Cascading Style Sheets. It controls the appearance, layout, colors, and design of a website.

JavaScript

JavaScript makes websites interactive. It allows developers to create dynamic features and useful functions.
